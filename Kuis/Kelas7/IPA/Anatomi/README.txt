Paket latihan anatomi mengikuti struktur JSON contoh pengguna.
File utama: soal_anatomi.json
Struktur utama: title, topic, subtitle, difficulty_summary, total_questions, passages, questions.
Setiap soal menggunakan number, difficulty, question, options, answer, explanation.
Soal tidak membutuhkan gambar eksternal sehingga field image/passage tidak digunakan.
